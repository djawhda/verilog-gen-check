# booth_mul4：4×4 位有符号 radix-4 Booth 乘法器

用 radix-4 Booth 算法实现 4 位有符号数乘法（这是 Booth 模拟乘法器电路的数字参考模型）。

## 接口

```verilog
module booth_mul4(
    input  wire signed [3:0] m,   // 被乘数 -8..7
    input  wire signed [3:0] q,   // 乘数 -8..7
    output wire signed [7:0] p    // 积 -56..64
);
```

## 行为（纯组合逻辑）

- 两个 Booth 数字：`d0` 由窗口 `{q[1], q[0], 1'b0}` 编码，`d1` 由窗口 `{q[3], q[2], q[1]}` 编码。编码规则 `d = -2*b2 + b1 + b0`（000/111→0，001/010→+1，011→+2，100→−2，101/110→−1）。
- 部分积 `pp0 = d0·m`，`pp1 = d1·m`，取值只有 0、±m、±2m，要用**取反和移位**得到，不能用乘法运算符 `*`。
- `p = pp0 + 4·pp1`（`4·pp1` 用左移 2 位实现）。注意中间量的位宽和符号扩展：`2m` 最多需要 5 位，`4·pp1` 最多 7 位，最终结果 8 位。
- 结果必须对全部 256 种输入等于 `m*q`。
